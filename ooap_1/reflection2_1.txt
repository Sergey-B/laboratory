2.2. Почему операция tail не сводима к другим операциям (если исходить из эффективной реализации)?

Потому что более эффективно хранить указатель на tail, чем итерировать через весь список. 

2.3. Операция поиска всех узлов с заданным значением, выдающая список таких узлов, уже не нужна. Почему?

Операция поиска всех узлов сводится к поиску следующего элемента и может быть им заменена.

Отличия:

нет предусловий у следующих методов:
  right // предусловие: правее курсора есть элемент;

  put_left // предусловие: список не пуст; <- отсутсвтует
  put_right // предусловие: список не пуст; 

  // постусловие: в списке один узел
  public void add_to_empty(T value);

  // предусловие: список не пуст; 
  public void remove();

  // постусловие: курсор установлен на следующий узел 
  // с искомым значением, если такой узел найден
  public void find(T value);

также было ошибкой думать что можно переиспользовать статусы одних операций в других, стоит относится к статусу как к state machine одного конкретного метода.
