Рефлексия на задание 7

Пример динамического связывания в решении на Java похож на мое решение на C#. 
За исключением того что в Java большинство методов считаются по умолчанию виртуальными и их не нужно специально помечать и разрешать override.

Нa Python решение не требует наличия ключевого слова override так как Python интерпретируемый язык с динамической типизацией
и поиск нужного метода происходит динамически в рантайме. 
В отличие от компилируемых Java и C#, где корректность проверяется на этапе компиляции.
